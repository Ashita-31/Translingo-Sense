## 📌 Overview

**TransLingo Sense** is an intelligent NLP-based application that:

- 🌍 Detects the language of user input  
- 🔄 Translates it into a selected target language  

💬 Example:
- "Bonjour" → French → *Hello*  
- "Hola amigo" → Spanish → *Hello friend*  
- "नमस्ते" → Hindi → *Hello*  

---

## 🧠 Features

- 🌍 Multi-language detection  
- 🔄 Real-time translation  
- ⚡ Fast and accurate predictions  
- 🧠 ML + NLP pipeline

- 📊 Works for short & long text
